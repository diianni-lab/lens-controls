# Human lens design

Design and evaluation of defocusing lenses for the NeuroFUS DPX-500 transducer.

The workflows optimize pillar width and lens thickness, with flat lenses as a comparison. Additional simulations validate the selected design across focal depths.

The analyses and plots correspond to Figures 1B–D, 2A–B, and S1A–B.

## Inputs and supplied results

Lens and transducer parameters are defined in the MATLAB code. Small `pressure_ratios.mat` summaries and plots are supplied in:

| Folder | Contents |
|---|---|
| `results/flat_lens_3mm_dist/` | Flat-lens summaries and plots |
| `results/variable_thickness_and_pillar_widths/` | Lens optimization summaries and plots |
| `results/variable_focus_9mm_lens_pillar_width_7/` | Focal-depth validation summaries and plots |
| `paper_plots/` | Pressure-field plots used in the manuscript |

Full simulation MAT files are not included and must be regenerated using the simulation workflows below.

## Reproduce summary plots

```matlab
run('setup_matlab_paths.m');
cd('human_lens_design');

% Pillar-width comparison
var_lens_thickness_and_pillar_width_3_plot_pressure_ratios

% Lens-thickness and flat-lens comparison
flat_lenses_3_plot_pressure_ratios

% Validation across focal depths
var_focus_3_plot_pressure_ratios
```

These scripts read the supplied −6-dB summaries and save plots in the corresponding results folders.

## Regenerate simulations

Run in `human_lens_design/`:

```matlab
% Flat-lens comparison
flat_lenses_1_simulate

% Pillared-lens optimization
var_lens_thickness_and_pillar_width_1_simulate

% Validation across focal depths
var_focus_1_simulate
```

| Workflow | Parameters |
|---|---|
| Flat lenses | Thicknesses 1–11 mm; 80-mm focal depth |
| Pillared lenses | Widths 1, 3, 5, 7, 9 mm; thicknesses 4–11 mm; 20 random layouts per configuration; 80-mm focal depth |
| Focal-depth validation | Selected 9-mm lens with 7-mm pillars; depths 50, 70, 90, 110, 130, 150 mm; 20 random layouts per depth |

Simulation MAT files are saved in the corresponding `results/` folders.

## Calculate pressure ratios

```matlab
flat_lenses_2_calc_pressure_ratios
var_lens_thickness_and_pillar_width_2_calc_pressure_ratios
var_focus_2_calc_pressure_ratios
```

The default contour is −6 dB. For −12-dB results, set `db_drop = 12` in the relevant calculation scripts and update the plotting paths to `press_ratio_12dB`.

## Reproduce pressure-field plots

For Figure 2, generate the additional fields by rerunning
`var_focus_1_simulate.m` with:

- `for focal_length_mm = [60 120]`
- `for seed = 8` in the lens simulation loop

The 90-mm fields are generated by the original sweep.

From the repository root:

```bash
python code/postprocessing/human_lens_design/plot_var_thickness_pillar_widths.py \
  --data-dir human_lens_design/results/variable_thickness_and_pillar_widths \
  --output-dir human_lens_design/paper_plots/var_thickness_pillar_widths/plots

python code/postprocessing/human_lens_design/plot_var_focus.py \
  --data-dir human_lens_design/results/variable_focus_9mm_lens_pillar_width_7 \
  --output-dir human_lens_design/paper_plots/var_focus/plots
```

Figure 1B uses seed 8 for pillar widths 1, 3, 5, and 7 mm,
and seed 10 for the 9-mm width.
